📚 Análise de Vendas para Livraria – Projeto Power BI
👨‍💼 Contexto do Projeto
Fomos contratados como analistas de dados pela consultoria Ilus para realizar nossa primeira demanda profissional: uma análise completa das vendas de uma livraria. Nosso objetivo é entregar insights estratégicos que ajudem o negócio a crescer de forma orientada por dados.

🎯 Objetivo
Realizar uma análise exploratória e analítica das vendas com foco em três frentes principais:

🛒 Produtos: Quais são os mais vendidos e rentáveis?

👩‍💼 Vendedores: Quem tem o melhor desempenho?

📈 Vendas ao longo do tempo: Como os resultados estão evoluindo?

Todas as análises foram feitas com o Power BI, utilizando DAX para criação de métricas, medidas e visualizações inteligentes.
